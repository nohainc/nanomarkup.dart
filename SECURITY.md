# Security policy

## Supported versions

The latest stable release receives security fixes. Older releases may be fixed
when the maintainers judge that practical.

## Reporting a vulnerability

Use GitHub's **Report a vulnerability** form on this repository's Security tab.
Do not disclose a suspected vulnerability in a public issue.

Include the affected version, runtime, minimal reproducer, expected impact, and
suggested mitigation. You should receive an acknowledgement within seven days.

For language-specification issues rather than Dart implementation defects, use
the security policy in the Nano Markup specification repository.
